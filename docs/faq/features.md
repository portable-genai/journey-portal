# Features and boundaries

Hrz9 composes configured application UIs and APIs into RM and Ops journeys. It owns the host,
route and identity boundary. Hrz1 owns guardrails, Hrz2 grounding, Hrz3 registry, Hrz4 promotion,
Hrz5 observability, and Hrz7 human review. Hrz9 links to those systems instead of duplicating
their engines.
